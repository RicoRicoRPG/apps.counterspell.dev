# apps.counterspell.dev

GitHub Pages site for Counterspell Games LLC's mobile apps.

- `app-ads.txt`: the authorized sellers file AdMob and the mediation networks crawl. Both games' store
  listings name `https://apps.counterspell.dev` as the developer website, so the crawler reads
  `https://apps.counterspell.dev/app-ads.txt`. Add a network's lines when its account is set up.
- `index.html`: the developer page the store listings link to.
- `CNAME`: the custom domain. DNS: a CNAME record `apps` -> `ricoricorpg.github.io` in Wix.
